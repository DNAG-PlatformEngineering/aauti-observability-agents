## Differences from media-nonprod

- **Own tenant `media-prod`**, not `media`: the retention policy keeps prod 30d (logs and metrics) and media nonprod 7d / 10d,
  and Mimir has only one metrics retention per tenant. Grafana datasources `Loki – Media-prod` / `Mimir – Media-prod`,
  in the same Grafana as everything else. The tenant password is generated by the hub chart and copied by `deploy.ps1`.
- **Regional cluster.** The kube context is `gke_aauti-media-prod_asia-south1_aauti-media-prod-as1-gke` (region, not zone).
  Alloy's 2Gi `standard-rwo` PVC is zonal, so the pod stays in the zone it was first scheduled in; every zone has at least one `apps` node.
- **Network.** The peering already existed, so [`../../network/aauti-media-prod.ps1`](../../network/aauti-media-prod.ps1) only checks it
  (it would recreate it if missing). Only the LB source ranges were added.
- Like media-nonprod: no node-exporter, no Prometheus Operator, agent and kube-state-metrics on `apps`
  (~120m CPU / 340Mi memory requested).

## Rollout (run from the office network / VPN, in this order)

```powershell
cd D:\aauti-observability-agents

# 0. Network check (read-only on the current state).
./network/aauti-media-prod.ps1 -WhatIf

# 1. Hub: tenant "media-prod" + LB source ranges. The gateway pod restarts once.
./clusters/aauti-hub-as1-obs-gke/observability/deploy.ps1

# 2. Hub Grafana: Media-prod datasources + dashboards (Grafana pod restarts once).
#    Note: grafana/deploy.ps1 on main also deploys the email alerting + SMTP (see the hub README, Alerts).
#    On 2026-10-06 this step ran from a checkout of fb95d9b + the Media-prod change, so alerting is not live yet.
./clusters/aauti-hub-as1-obs-gke/grafana/deploy.ps1

# 3. Spoke: agent in the new namespace observability-agent-mediaprod.
./clusters/aauti-media-prod-as1-gke/observability-agent/deploy.ps1

# 4. Verify (read-only), after ~2 minutes.
./clusters/aauti-media-prod-as1-gke/observability-agent/verify.ps1
```

**Rollback:**
```powershell
helm --kube-context gke_aauti-media-prod_asia-south1_aauti-media-prod-as1-gke -n observability-agent-mediaprod uninstall observability-agent-mediaprod
kubectl --context gke_aauti-media-prod_asia-south1_aauti-media-prod-as1-gke delete namespace observability-agent-mediaprod
```
Nothing else on the cluster is changed by the install. To remove it from the hub too, delete `media-prod` from the hub values,
the LB ranges and Grafana, and redeploy observability and Grafana.

## Dashboards (Grafana → folder **Media-prod**)

The shared templates *Cluster health*, *Resource usage* and *Workloads & logs*, with
**Environment (prod) → Cluster → Namespace** selectors.

Raw queries: *Explore* → `Loki – Media-prod` (e.g. `{cluster="aauti-media-prod-as1-gke", namespace="aauti-media-api-prod"}`)
or `Mimir – Media-prod` (e.g. `kube_pod_container_status_restarts_total{cluster="aauti-media-prod-as1-gke"}`).
